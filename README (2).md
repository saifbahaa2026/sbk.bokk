# منيو مكتبة دار سبك — نسخة GitHub + قاعدة بيانات Supabase

الموقع يشتغل على **GitHub Pages** (مجاني)، والبيانات (الأقسام، الكتب، الأسعار، النبذ، معلومات التواصل، الثيم) محفوظة بقاعدة **Supabase** (مجانية، بدون بطاقة)، وأغلفة الكتب تنرفع لمخزن Supabase.
أي تعديل من لوحة التحكم ينحفظ فوراً ويظهر عند **كل الزبائن على كل الأجهزة**: عند فتح الصفحة، وعند الرجوع لها، وكل دقيقة ونص تقريباً وهي مفتوحة.

## ملفات المجلد
| الملف | شنو يسوي |
|---|---|
| `index.html` | الموقع كله + لوحة التحكم |
| `supabase_setup.sql` | ينشئ الجداول والحماية ومخزن الأغلفة |
| `favicon.png` | أيقونة الصفحة |

## الخطوة 1: إنشاء قاعدة البيانات
1. ادخل **supabase.com** وسوّي حساب (يكفي حساب GitHub أو إيميل).
2. **New project**: اكتب اسم (مثلاً `sbk-menu`)، كلمة سر قوية للقاعدة (احفظها)، واختار أقرب منطقة، ثم Create. انتظر دقيقتين لحد ما يجهز.
3. من القائمة اليسار: **SQL Editor ← New query** ← الصق محتوى `supabase_setup.sql` كله ← **Run**. لازم تطلع "Success".

## الخطوة 2: حساب صاحب المكتبة (مهم للحماية)
1. **Authentication ← Users ← Add user ← Create new user**.
   اكتب إيميل وكلمة سر **قوية**، وفعّل **Auto Confirm User**، ثم Create.
2. **Authentication ← Sign In / Providers** (أو Settings) ← عطّل **Allow new users to sign up**.
   هذا يمنع أي شخص يسوي حساب ويعدّل المنيو. **لا تنساه.**

## الخطوة 3: ربط الموقع بالقاعدة
1. **Project Settings ← API** (أو API Keys): انسخ **Project URL** و **anon public key** (أو Publishable key).
2. افتح `index.html` بأي محرر نصوص، وفي أول الملف دور على `window.SBK_CONFIG` وبدّل القيمتين:
```js
window.SBK_CONFIG={
  SUPABASE_URL:"https://xxxx.supabase.co",
  SUPABASE_ANON_KEY:"المفتاح_العام"
};
```
المفتاح العام (anon) مو سري، وحمايته من قواعد الـ RLS اللي سويناها بالـ SQL. **لا تحط أبداً مفتاح service_role.**

## الخطوة 4: الرفع على GitHub
1. سوّي حساب على **github.com** ← **New repository** (مثلاً `sbk-menu`) ← Public.
2. **Add file ← Upload files**: ارفع `index.html` و `favicon.png` ← Commit.
3. **Settings ← Pages**: Source = *Deploy from a branch*، Branch = `main` و `/ (root)` ← Save.
4. بعد دقيقة يطلع الرابط: `https://اسم-حسابك.github.io/sbk-menu/`
   (تكدر تربطه بدومين خاص من نفس الصفحة).

## الخطوة 5: رفع البيانات الأولية (مرة وحدة)
1. افتح رابط الموقع.
2. اضغط على **الشعار 5 مرات** ← اكتب الرمز `8080`.
3. سجّل دخول بإيميل وكلمة سر الخطوة 2 (يبقى مسجّل بالجهاز).
4. بأعلى اللوحة يطلع زر **"رفع البيانات الأولية"**: اضغطه مرة وحدة وانتظر لحد ما يطلع "تم الحفظ ✓". هذا يرفع الأقسام والكتب الحالية وأغلفتها للقاعدة.

بعدها كل شي يتعدّل من اللوحة.

## كيف يعدّل العميل من أي جهاز
1. يفتح الرابط ← الشعار 5 مرات ← `8080` ← إيميل وكلمة سر.
2. يعدّل: كتب، أغلفة، أسعار، نبذ، أقسام، أيقونات، معلومات التواصل، الثيم.
3. التعديل ينحفظ تلقائياً (يطلع "تم الحفظ ✓") ويظهر عند الجميع.

## ملاحظات
- **الرمز 8080** يخفي اللوحة فقط. الحماية الحقيقية هي تسجيل الدخول + قواعد القاعدة: بدون حساب الأدمن ما أحد يكدر يعدّل. لتغيير الرمز دور على `8080` داخل `index.html`.
- مشروع Supabase المجاني **يتوقف إذا ما صار عليه أي نشاط لمدة أسبوع**. زيارات الزبائن تحسب نشاط، فما تتوقف عادةً. وإذا توقف، تشغّله من لوحة Supabase بضغطة.
- الحدود المجانية: قاعدة 500MB، ومخزن صور 1GB، وتحميل 5GB بالشهر. الأغلفة تنضغط تلقائياً (حوالي 20-30KB للغلاف)، فتكفي لآلاف الزبائن.
- لما تحذف قسم أو كتاب، صورة الغلاف تبقى بالمخزن (ما تأثر). تكدر تنظفها من **Storage ← covers** إذا تحب.
- بيانات المنيو الحالية موجودة داخل `index.html` نفسه، وتظهر إذا القاعدة ما اشتغلت.
- نسخة احتياطية: من Supabase ← Table Editor تكدر تصدّر أي جدول CSV بأي وقت.
